# P4 处理结果的 PNG 预览

无参数入口继续保持 P4 行为。新增 P5 用法见 [CCM PNG 预览](p5_png_preview.md)。

PNG 展示正式 RTL 流水线的实际输出，数据链路为 RGGB RAW12 → BLC →
AWB Gain → 双线性 Demosaic → RGB12。原始图案是确定性的 16×16 合成测试
图像；这个预览用于观察颜色、边缘和参数变化，数值验收仍由 RGB36 精确比较完成。

## 复现命令与依赖

在仓库根目录运行：

```sh
make test-p4-demosaic
PYTHONDONTWRITEBYTECODE=1 python3 tools/export_demosaic_png.py
```

第一行生成输入、独立黄金和 RTL 实际输出，并完成完整 P0–P4 回归。如果已经
保留验收产物，可以只运行第二行；它不重新仿真，也不改写输入、黄金或 RGB dump。
导出脚本根据自身路径定位仓库，因此也支持从其他目录以绝对脚本路径运行。

导出依赖 NumPy 和 Pillow，当前验证环境为 Python 3.6.6、NumPy 1.19.5、
Pillow 6.2.2。Pillow 为 PNG 预览的可选依赖，未加入模型或正式回归入口。

## 图案与两帧参数

总览的四列从左到右如下：

| 图案 | 内容 | 主要观察点 |
| --- | --- | --- |
| `constant_rgb` | 输入 RGB12 为 (512, 1024, 2048) 的常量场 | 各通道的黑电平和增益变化，输出空间均匀性 |
| `rgb_gradient` | 三个通道按坐标形成整数渐变 | 去马赛克后的平滑变化和边界延拓 |
| `color_blocks` | 红、绿、蓝、白四个色块 | 色块交界处的双线性混色及通道饱和 |
| `edge_pattern` | 垂直、水平和对角边缘组合 | 不同方向边缘上的插值过渡 |

总览上排为 frame 0，下排为 frame 1。脚本标签对应
`scripts/run_demosaic_pipeline.sh` 中的正式两帧配置：

| 帧 | BLC 黑电平 | gain_r | gain_g | gain_b | Q12 原始增益编码 R/G/B |
| --- | --- | --- | --- | --- | --- |
| 0 | 64 | 1.50 | 1.00 | 2.00 | 6144 / 4096 / 8192 |
| 1 | 128 | 1.00 | 1.25 | 0.50 | 4096 / 5120 / 2048 |

BLC 扣除黑电平并将负值限制为零；AWB 按 RGGB 位置施加三路增益，两个
绿色位置共用 gain_g，结果限制在 RAW12 范围。Demosaic 在处理后的 Bayer
数据上进行双线性插值。两排颜色不同来自两组实际配置；色块边缘的混色来自
插值，最近邻放大仅复制已有像素。

## 输入检查与显示映射

工具读取 `testdata/output/p4_demosaic/integration/<pattern>/frame_<n>.mem`，
每行格式为九个十六进制字符 `RRRGGGBBB`。每个通道分别占 12 位，像素按
从左到右、从上到下的 raster 顺序恢复。

宽高来自对应的 `inputs/16x16/<pattern>_16x16.json`。工具复用严格 RGB36
解析器，检查实际像素数为 W×H，并与 `golden/<pattern>/frame_<n>.mem`
逐像素比较。八份输出全部匹配后才开始生成图片；缺失文件、非法格式、数量
错误或数值不一致均使导出失败。

PNG 使用每通道 8 位 RGB，所有图案共用固定整数映射：

```text
PNG8 = (RGB12 × 255 + 2047) // 4095
```

该映射将 0 和 4095 分别映射为 0 和 255，采用最接近整数的舍入。乘法前
提升至 uint32，避免溢出；不对各图单独拉伸亮度，不进行自动曝光或伽马校正。
这是线性数值预览，尚未实现的后续颜色处理不参与图片生成。

原尺寸 PNG 为 16×16，放大版为 256×256，采用最近邻复制每个像素 16×16
次。PNG8 会量化 12 位数据，原始精度保留在 RGB36 `.mem` 中。保存后工具
重新打开八份原尺寸 PNG，检查格式、RGB 模式、尺寸和全部 RGB8 像素。

## 输出位置

所有产物集中在 `testdata/output/p4_demosaic/png/`：

| 文件 | 内容 |
| --- | --- |
| `rtl_rgb_overview.png` | 四列图案、两排配置的总览，1124×710 |
| `<pattern>_frame_<n>.png` | 八份原尺寸 16×16 实际输出 |
| `<pattern>_frame_<n>_x16.png` | 八份 256×256 最近邻放大版 |
| `manifest.json` | 实际 dump 路径、尺寸、映射、放大方式及黄金一致性记录 |

这些图片和清单均属于可重建产物，由 `.gitignore` 忽略，`make clean` 随 P4
输出一起清理。版本库保存导出工具及本文说明，不保存生成图片、仿真数据库或
本地报告。导出过程不在工具目录生成 Python 缓存。
